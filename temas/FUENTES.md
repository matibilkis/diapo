# Tipografías que vienen con los temas

Están recortadas a `.woff2` desde Google Fonts y se distribuyen bajo la SIL Open Font License 1.1.
El texto completo de cada licencia está al lado de los archivos, en `fonts/licencias/`.

| Familia | Tema | Licencia |
|---|---|---|
| Amatic SC | oscuro | SIL OFL 1.1 — Copyright 2015 The Amatic SC Project Authors |
| Montserrat | oscuro | SIL OFL 1.1 — Copyright 2024 The Montserrat.Git Project Authors |
| STIX Two Text | claro | SIL OFL 1.1 — Copyright 2001-2021 The STIX Fonts Project Authors |

`diapo importar` baja de Google Fonts las tipografías que use el archivo original y las deja en la carpeta `fonts/`
de esa presentación. Esas no pasan por este repo: si vas a repartir una presentación importada, mirá la licencia
de cada familia en fonts.google.com.
